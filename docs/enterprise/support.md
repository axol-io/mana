## Service Level Agreements

### Response Times

| Severity | Community | Professional | Enterprise | Mission Critical |
|----------|-----------|-------------|------------|------------------|
| Critical | Best Effort | 24 hours | 4 hours | 1 hour |
| High | Best Effort | 48 hours | 24 hours | 4 hours |
| Medium | Best Effort | 72 hours | 48 hours | 24 hours |
| Low | Best Effort | 5 days | 72 hours | 48 hours |

### Severity Definitions

#### Critical (P0)
- Production system completely down
- Data loss or corruption
- Security breach
- Complete service unavailability

#### High (P1)
- Major feature not working
- Significant performance degradation
- Workaround available but difficult

#### Medium (P2)
- Minor feature not working
- Performance issues with workarounds
- Documentation errors

#### Low (P3)
- Cosmetic issues
- Enhancement requests
- General questions

## Support Process

### Ticket Submission

1. **Create Account**: Register at support.axol.io
2. **Submit Ticket**: Provide detailed information
3. **Initial Response**: Acknowledgment within SLA
4. **Investigation**: Technical team reviews issue
5. **Resolution**: Fix provided or workaround suggested
6. **Verification**: Customer confirms resolution
7. **Closure**: Ticket closed with satisfaction survey

### Required Information

When submitting a ticket, please provide:

#### System Information
```bash
# Mana version
/opt/mana/bin/mana eval "Application.spec(:mana)[:vsn]"

# System details
uname -a
lscpu | head -20
free -h
df -h

# Network configuration
ip addr show
netstat -tuln
```

#### Configuration Details
- Mana configuration files (sanitized)
- Network topology diagram
- Hardware specifications
- Operating system version

#### Error Information
- Complete error messages and stack traces
- Log files (with sensitive data removed)
- Steps to reproduce the issue
- Expected vs actual behavior
